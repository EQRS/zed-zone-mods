# 模组配置中心 · MOD CONFIG

给 **所有** ZED ZONE 代码模组提供统一的游戏内配置面板。

主菜单点「模组配置」即可打开，不用再手动改 cfg 文件。

## 功能

- **零配置接入**：任何用 BepInEx `Config.Bind()` 写配置的模组，面板会自动解析
- **六类控件**：开关 / 数字 / 滑条 / 文本 / 按键选择 / 按钮
- **安全写入**：只改数值，注释、空行、换行符全部保留，写入前备份 `.bak`
- **只写改动项**：不会覆盖你在别处的修改

## 给模组作者

三种接入方式（详见 [docs/接入指南.md](./docs/接入指南.md)）：

1. **零配置** —— 什么都不用做
2. **JSON 声明** —— 在模组目录放 `modconfig.json`
3. **SDK 代码** —— 调用 `ModConfigApi.Register()`

不引用本 DLL 也能用，通过反射软调用即可。

## 目录

```
src/
├── PanelPlugin.cs          插件入口
├── GameLocator.cs          游戏根目录定位（6 种策略）
├── schema/                 cfg 解析与声明加载
├── ui/                     面板界面与控件
├── actions/                按钮动作分发
└── api/                    给模组作者的 SDK
```
