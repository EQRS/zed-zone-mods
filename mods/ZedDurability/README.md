# 自定义耐久 · Custom Durability

**ZED ZONE（隔离区 - 丧尸末日生存）代码模组**

![自定义耐久](dist/cover.png)

---

## 这是什么

给游戏里所有会磨损的东西，**按物品类别分别设置耐久消耗速度**。

- 想让枪打了不坏？把**枪械零件**调成 `0`（枪械本体的耐久在配件上）
- 想让近战武器磨得慢一半？调成 `0.5`
- 
**不改存档、不改游戏文件，随时可删。**

---

## 安装前提

必须先安装代码模组加载器（工坊 ID **3834614258**，ZedModKit / BepInEx 6）：

1. 订阅加载器物品
2. 进入 `steamapps\workshop\content\1211600\3834614258\`
3. 双击 `install.cmd`
4. **必须从 Steam 启动游戏**（直接双击 ZEDZONE.exe 会秒退）

主菜单左上角出现 `ZED MODS: N code mod(s) loaded` 说明加载器已生效。

---

## 安装本模组

把 `ZedDurability.dll`（和 `mod.json`）放到：

```
<游戏目录>\Mods\ZedDurability\ZedDurability.dll
```

从 Steam 启动游戏即可。主菜单左上角的模组列表里会出现 **Custom Durability 1.0.4**。

---

## 配置说明

首次启动游戏后自动生成配置文件：

```
<游戏目录>\BepInEx\config\zedzone.durabilitymultiplier.cfg
```

配置分成**两个独立段落**，互不影响。

### 一、消耗系数 —— 影响「用得多快」

```ini
[Multipliers 倍率]
MeleeWeapon_近战武器 = 1
GunPart_枪械零件 = 1
Clothing_衣物护甲 = 1
Container_容器 = 1
...
```

| 填什么 | 效果 |
|---|---|
| `1` | 原版消耗（默认） |
| `0.5` | **消耗减半**（耐用一倍） |
| `0` | **完全不消耗**（永不磨损） |
| `2` | 消耗翻倍（更容易坏） |
| `0.1` | 消耗只有原来的 1/10 |

范围：0 – 100。

### 全部 14 个档位

| 配置键 | 对应内容 | 说明 |
|---|---|---|
| `Material_材料` | 杂项材料、通用手工具 | 部分材料有耐久 |
| `Food_食物` | 食物 | |
| `FaceMask_面罩` | 防毒面具、一次性口罩 | |
| `MeleeWeapon_近战武器` | 刀、斧、棍棒 | |
| `RangedWeapon_枪械` | 枪械本体 | |
| `Clothing_衣物护甲` | 衣服、护甲 | |
| `Magazine_弹匣` | 弹匣每次射击 | |
| `GunPart_枪械零件` | 枪管、消音器等配件 | 与枪械本体分开计算 |
| `Deployable_可放置物` | 炮塔、陷阱等 | |
| `Container_容器` | 水瓶、水壶本体 | |
| `Liquid_液体` | 液体 | |
| `LightingTool_照明工具` | 手电、火把本体 | 独立档位 |
| `FishBait_鱼饵` | 鱼饵 | 独立档位 |
| `LiquidUse_液体消耗` | 喝水/倒水的水量 | 独立档位 |

> **v1.0.3 移除了 5 个无效档位**：弹药、箭矢、投掷物、背包、斗篷。
> 这些物品在游戏里没有耐久机制，设了也不生效。
>
> **v1.0.3 关闭了「耐久上限」功能**：游戏内该功能实现路径尚在验证中，
> 当前版本只提供**耐久消耗系数**（已确认有效）。

## 重要概念说明

### 枪械的磨损由两部分组成

- **`RangedWeapon_枪械`** —— 枪械本体耐久
- **`GunPart_枪械零件`** —— 装在上面的配件（枪管、消音器等）

想让整把枪更耐用，**两个都要调**。

> v1.0.4 修复：枪械本体耐久的实际存储位置是 `ItemData.properties[0]`（不是 `durability` 字段），此前版本对枪械本体的调整不生效，现已修复并实测验证。

### 容器耐久 ≠ 水量

- **`Container_容器`**：瓶子本身的磨损（用久了瓶子会坏）
- **`LiquidUse_液体消耗`**：每次喝水消耗多少水

想让一瓶水喝得更久 → 调 `LiquidUse_液体消耗`。

### 照明工具不包含电池

`LightingTool_照明工具` 只管工具本体的磨损。**靠电池的手电扣的是电池电量，不受这个档位影响。**

## 生效方式

**修改配置后需要重启游戏才生效。**

本模组不提供热重载（已验证在 IL2CPP 环境下按键捕获不可靠），改倍率是低频操作，重启一次即可。

---

## 联机说明

代码模组不会随游戏的 Mods 同步给其他玩家。

**联机时请让所有参与者安装本模组的同一版本**，否则：

- 没装的人按各自的原版数值计算
- 改数值类模组在带 Mods 的会话或排位里可能被判异常

**单机游玩无此问题。**

## 排错

| 现象 | 处理 |
|---|---|
| 游戏内没有效果 | 查看 `BepInEx\LogOutput.log`，应有 `Custom Durability 1.0.4 loaded, patched 13 method(s).` |
| 改动配置没反应 | **重启游戏**后再看 |
| 想确认倍率是否读到 | 日志里的 `生效倍率：...` 行会列出所有非 1.0 的档位 |
| 装完游戏起不来 | 把 `Mods\ZedDurability` 改名为 `ZedDurability.disabled` |
| 补丁挂载失败 | 游戏大版本更新改了方法签名，需要等模组适配 |

## 卸载

删除 `<游戏目录>\Mods\ZedDurability\` 整个文件夹即可，存档不受影响。

配置文件可留可删：`BepInEx\config\zedzone.durabilitymultiplier.cfg`

## 技术说明

- 游戏版本：Unity 2023.1.18f1 / IL2CPP x64
- 依赖：BepInEx 6.0.0-be.793 + HarmonyX + Il2CppInterop
- 模组 GUID：`zedzone.durabilitymultiplier`
- 生效补丁：13 个 Harmony 补丁，覆盖通用耐久消耗、衣物护甲、近战挥砍、枪械配件磨损、载具货箱、液体消耗等通路
- 所有补丁均有异常兜底：查不到物品类别、数据异常时一律回退原版数值，不会让游戏崩溃
